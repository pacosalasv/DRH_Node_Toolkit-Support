## Read this first

Node Toolkit is a plan, not a product. There's nothing to download and no release date. This repository exists so the idea has a place to be argued about before I spend three months on it.

## The idea

Node-editor utilities for cleanup, layout, resizing, reroute removal, color control, and graph organization. The boring part of shader and geometry-node work is maintenance: frames that drifted, reroutes that made sense in March, node trees that only the person who built them can read.

## What's decided and what isn't

Settled: it would be a node-editor tool, not a render or material library, and it would work where Blender's node editors exist rather than in one of them.

Open: whether the layout and cleanup half is worth its own add-on at all, or whether it belongs inside something already released. That's the question I haven't answered, and it's why this page doesn't promise features.

## The honest alternative

If your problem is color and ramps inside node trees, [Color Ramp Studio](https://github.com/pacosalasv/DRH_Color_Ramp_Studio-Support) is released and free. If your problem is knowing what a scene's materials and textures actually are before you hand it over, [Scene Material Inventory](https://github.com/pacosalasv/DRH_Scene_Material_Inventory-Support) does that today.

Neither fixes messy graph layout. If that's the part that costs you time, say so in an issue and describe the graph you were staring at.
