# DRH - Node Toolkit

Planned node-editor utilities for cleanup, layout, resizing, reroute removal, color control, and graph organization.

| Status | Distribution |
|---|---|
| Planned | No public installable release |

## Repository scope

This repository reserves the public documentation and support location for DRH - Node Toolkit. Product direction and status may be published here before a release; installable packages are not.

When an official release is available, distribution is expected through [BlendKit](https://www.blendkit.com/?query=author_id:205846). GitHub remains the documentation and support layer unless that model changes.
